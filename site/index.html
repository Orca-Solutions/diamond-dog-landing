03 / FAIR QUESTIONS

Still in
the workshop.

The design is written down. A first experiment is under way. Nothing has shipped yet.

Can I try it yet?+

Not yet. We’re testing the design on existing platforms first. This page introduces the project; it isn’t an invitation to hand over an account.

Is this just for AI?+

No. The same rules apply to apps, scripts and AI participants. Diamond Dog is about the arrangement for delegated work, whoever—or whatever—is doing it.

Where will it run?+

The intended environment is an open-source layer on Linux: a headless runtime and an inspector for seeing what a job may still do and what happened. It isn’t a new desktop.

What does cancelling mean?+

The design aims to make clear which future work cancellation would prevent. It cannot promise to reverse something that has already happened in an outside service.
